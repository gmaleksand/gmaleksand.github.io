**Задача 2. а)** В режим на самопроизволни периодични изменения на тока при напрежение $U_2 = 80 \text{ V}$ имаме

$$I_{\text{min}} = \frac{U_2}{R_2} = 0,8 \text{ A , } \quad I_{\text{max}} = \frac{U_2}{R_1} = 1,6 \text{ A . (2 т.)}$$

**б)** При приложено напрежение $U_1 = 60 \text{ V}$ нелинейният елемент достига стационарно състояние при съпротивление $R_1$ (0,5 т.). Тогава имаме
$\frac{U_1^2}{R_1} = \alpha(t_3 - t_0),$ (0,5 т.)
откъдето намираме
$\alpha = \frac{U_1^2}{R_1(t_3 - t_0)} = 1,2 \text{ W/K}.$ (1 т.)

в) При напрежение $U_2$ и съпротивление на елемента $R_1$ стационарно състояние би се
установило при температура $t_4$, която удовлетворява условието
$\frac{U_2^2}{R_1} = \alpha \left(t_4 - t_0\right),$ (0,5 т.)

откъдето намираме

$t_4 = t_0 + \frac{U_2^2}{\alpha R_1} = 126,7\text{ }^\circ\text{C}$. (0,5 т.)

Тъй като $t_4 > 100\text{ }^\circ\text{C}$, при достигане на $t_1 = 100\text{ }^\circ\text{C}$ съпротивлението на елемента скообразно се променя и става $R_2$, а токът – $I_{\text{min}}$. (0,5 т.)

Аналогично, температурата $t_5$, при която се установява стационарно състояние, когато съпротивлението е $R_2$, се определя от

$\frac{U_2^2}{R_2} = \alpha \left(t_5 - t_0\right),$ (0,5 т.)

откъдето намираме

$t_5 = t_0 + \frac{U_2^2}{\alpha R_2} = 73,3^\circ\text{C}.$ (0,5 т.)

Следователно при достигане на $t_2 = 98^\circ\text{C}$, съпротивлението на елемента скообразно се връща към стойност $R_1$. (0,5 т.)

**г)** Нека времето за нагряване на елемента от $t_2 = 98^\circ\text{C}$ до $t_1 = 100^\circ\text{C}$ е $\tau_1$. Тогава имаме

$\frac{U_2^2 \tau_1}{R_1} = c(t_1 - t_2) + \alpha \left(t_{\text{cp}} - t_0\right)\tau_1,$(1 т.)

откъдето намираме

$\tau_1 = \frac{c(t_1 - t_2)}{\frac{U_2^2}{R_1} - \alpha \left(t_{\text{cp}} - t_0\right)} = 0,18\text{ s}$. (0,5 т.)

Аналогично времето $\tau_2$ за охлаждане от $t_1 = 100^\circ\text{C}$ до температура $t_2 = 98^\circ\text{C}$ се определя от условието

$\frac{U_2^2 \tau_2}{R_2} + c(t_1 - t_2) = \alpha \left(t_{\text{cp}} - t_0\right)\tau_2$, (1 т.)

откъдето намираме

$\tau_2 = \frac{c(t_1 - t_2)}{\alpha \left(t_{\text{cp}} - t_0\right) - \frac{U_2^2}{R_2}} = 0,19\text{ s}$. (0,5 т.)

За периода намираме

$T = \tau_1 + \tau_2 = 0,37\text{ s}.$ (1 т.)

**Задача 3.а)** По определение за период на пружинно махало имаме

$T_0 = 2\pi \sqrt{\frac{m}{k}} = 0,31\text{ s}.$ (2 т.)

б) Индуцираният в металната равнина електричен заряд е обратен по знак на заряда q
(0,5 т.). Следователно имаме q' < 0 (0,5 т.).

в) Нека равновесното положение на незареденото пружинно нахало се намира на
височина $x_0$ над металната равнина. Тогава в равновесното положение на зареденото
пружинно махало, което се намира на разстояние а под другото (0,5 т.), ще бъде
изпълнено условието
$ka = \frac{e^2}{4(x_0 - a)^2}$, (1 т.)

където $e^2 = \frac{q^2}{4\pi \varepsilon_0}$.

Ако отклоним зареденото махало на разстояние x вертикално надолу възниква
връщаща сила

$$F = k (a + x) -\frac{e^2}{4(x_0-a-x)^2} = ka-\frac{e^2}{4(x_0-a)^2}+kx+\frac{e^2}{4}\left(\frac{1}{( x_0 - a) ^2}-\frac{1}{( x_0 - a - x)^2}\right),$$

(2 т.)
откъдето намираме

$$F = kx +\frac{e^2}{4}\frac{-2( x_0 - a ) x + x^2}{( x_0 - a)^2 ( x_0 - a - x)^2}.$$

 (1 т.)

Тази сила е еластична, когато x < < ( x0 - a ) и има вида
$F \approx \left( k - \frac{e^2}{2(x_0 - a)^3} \right) x .$ (1 т.)

Тогава периодът
$T = 2\pi \sqrt{\frac{m}{k - \frac{e^2}{2(x_0 - a)^3}}} = \frac{T_0}{\sqrt{1 - 4a \left( \frac{ka}{e^2} \right)^{1/2}}} \approx 0,35 \text{ s},$ (1,5 т.)

където е отчетено, че

$$\frac{1}{(x_0 - a)^3} = \left( \frac{4ka}{e^2} \right)^{3/2} .$$
